# 오늘 뭐 먹지 · 가맹점 찾기

React + TypeScript + CSS 및 카카오맵 Web SDK로 만든 춘천시 아동급식카드 가맹점 검색 프로토타입입니다.

## 실행

1. 카카오디벨로퍼스 JavaScript 키의 SDK 도메인에 사용할 주소(`http://localhost:5173`, `http://127.0.0.1:5173`)를 등록합니다. 앱의 카카오맵 사용 설정도 확인합니다.
2. Git에서 제외되는 `.env.local`에 `VITE_KAKAO_MAP_APP_KEY=발급받은_키`를 설정합니다. JavaScript 키는 브라우저에서 사용하는 공개 키이므로 등록 도메인을 제한합니다. REST/Admin 키를 입력하지 않습니다.
3. `npm.cmd install` 후 `npm.cmd run dev`를 실행합니다. 환경 변수 변경 후에는 개발 서버를 재시작합니다.

## 검증

```powershell
node --experimental-strip-types --test tests/*.test.ts
npm.cmd run build
```

검색(매장명·주소·메뉴), 업종·영업·배달 필터, 시청 기준 예시 거리 정렬, 매장 상세 선택, 실제 지도 드래그·확대·축소, 지역 설정 안내를 제공합니다. 모바일에서는 목록 아래에 지도를 표시합니다.

모든 매장, 주소, 전화번호, 영업시간, 가격 및 거리는 UI 검토용 예시입니다. SDK services로 예시 주소를 좌표 변환하므로 실제 매장 위치나 가맹 여부를 보장하지 않습니다. 변환 실패 주소는 안내 후 마커를 제외하며 목록에는 유지합니다. 실제 공공데이터는 아직 연결하지 않았습니다. GPS 위치는 수집하지 않고 위치 버튼은 춘천시청으로 이동합니다. 전화 버튼은 예시 안내를 표시하고 길찾기는 카카오맵 외부 검색으로 연결됩니다. 지역은 춘천시만 지원합니다.

SDK는 한 번 로드하며 네트워크 오류·키 누락 시 안내와 재시도를 제공합니다. 지도 사용 시 Kakao에 SDK·지도·주소 검색 요청이 발생합니다. 실제 지도 인증과 타일 표시 여부는 등록 도메인의 브라우저에서 확인해야 합니다.

데이터: src/merchants.ts / 지도: src/KakaoMap.tsx, src/kakao.ts / 화면: src/App.tsx / 스타일: src/App.css, src/index.css

## 숫자 마커와 선택 지역 목록

예시 매장은 총 16개이며 모두 춘천 지역의 검증되지 않은 예시 좌표를 갖습니다. 새 데이터에 coordinates가 없으면 기존 SDK 주소 검색을 사용합니다.

지도를 축소하면 카카오 MarkerClusterer가 화면상 80px 범위의 가까운 매장을 묶고 개수를 표시합니다(지도 레벨 4부터). 숫자 마커를 클릭하거나 키보드 Enter/Space로 선택하면 해당 묶음의 ID 목록을 저장하고 그 중심으로 이동·확대합니다. 왼쪽은 그 매장들만 표시하며, 지도의 다른 묶음은 계속 선택할 수 있습니다. 지도 확대 뒤 묶음이 나뉘어도 선택한 목록은 유지됩니다.

`전체 목록 보기`로 현재 검색·필터에 해당하는 전체 목록으로 돌아갑니다. 검색 실행이나 업종·영업·배달 필터 변경은 지역 선택을 해제하고, 거리순 변경은 선택 지역을 유지합니다. 숫자는 전체 검색 결과에 따른 가맹점 수이며 음식점만 보려면 일반음식점 필터를 사용합니다.
