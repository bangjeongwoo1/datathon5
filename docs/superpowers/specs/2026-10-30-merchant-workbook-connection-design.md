# 가맹점 데이터 연결 설계

## 의도

더미 매장 대신 실제 춘천시 아동급식카드 가맹점 목록을 검색 화면에 사용한다. 사용자는 매장명·주소·업종으로 실제 데이터에서 가맹점을 찾을 수 있어야 한다.

## 목표

- CSV의 가맹점 행을 화면 데이터로 변환한다.
- `가맹점명`, `가맹점ID`, `소재지도로명주소`, `업종명`, `공식_업태명`을 보존한다.
- 목록과 검색 결과에서 전화번호 및 전화 버튼을 제거한다.
- 좌표가 검증된 가맹점만 지도 마커로 표시한다.

## 제외 범위

- 관리기관 전화번호를 매장 전화번호로 대체하거나 매장별 번호를 추정하지 않는다.
- 확인이 필요한 비가맹 기록을 가맹점 목록에 섞지 않는다.
- CSV를 브라우저에서 직접 읽거나 해석하지 않는다.

## 데이터 흐름

`A_가맹점_좌표통합.csv`에서 시작해, 필요하면 REST API로 생성한 `_보완.csv`를 우선 사용한다. Python 변환기가 `frontend/src/data/merchants.generated.ts`를 만들고, React는 번들에 포함된 생성 파일만 읽는다.

### 컬럼 매핑

| 화면 필드 | 원본 컬럼 | 규칙 |
| --- | --- | --- |
| `id` | `가맹점ID` | 숫자 ID를 사용한다. |
| `name` | `가맹점명` | 그대로 표시한다. |
| `address` | `소재지도로명주소` | 그대로 표시하고 검색에 사용한다. |
| `rawCategory` | `업종명` | 세부 업종 필터에 사용한다. |
| `detailCategory` | `공식_업태명` | 값이 있으면 사용하고, 없으면 `업종명`을 사용한다. |
| `category` | `업종명` | 마커 색상용 큰 분류로 변환한다. |
| `coordinates` | `위도`, `경도` | 유효한 값이 모두 있을 때만 마커 위치로 사용한다. |

## 화면과 지도 동작

- 한식·중식·일식·양식·제과점·편의점·마트로 세부 필터링한다.
- 한식·중식·일식·양식은 지도에서 모두 일반음식점 색상으로 표시한다.
- 저장된 좌표가 없는 매장은 목록에는 유지하고 지도 마커만 생략한다.
- 생성 파일은 원본 CSV를 변경하지 않는다.
