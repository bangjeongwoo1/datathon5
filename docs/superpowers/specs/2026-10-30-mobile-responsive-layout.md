# 모바일 반응형 레이아웃 설계

## 목표

데스크톱 분할 화면은 유지하면서 휴대전화에서도 가맹점 찾기를 편하게 사용하도록 한다.

## 선택한 레이아웃

- 화면 너비 760px 이하에서는 헤더, 안내, 검색·필터, 가맹점 목록, 지도 순서를 유지한다.
- 업종 칩은 한 줄 가로 스크롤로 표시해 읽기와 터치가 쉽도록 한다.
- 목록 높이를 제한해 모든 카드가 끝나기 전에 지도로 이동할 수 있게 한다.
- 마커·지도 조작 도구·선택 매장 정보를 볼 수 있는 높이를 유지한다.
- 화면 너비 390px 이하에서는 헤더가 넘치지 않도록 찾기 버튼을 짧게 표시한다.

## 제약

- 데스크톱·태블릿 디자인과 가맹점·지도 동작은 유지한다.
- 새 의존성을 추가하지 않는다.
- 기존 한국어 문구와 키보드 포커스 동작을 유지한다.
