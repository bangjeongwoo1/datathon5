# 모바일 반응형 레이아웃 구현 계획

**목표:** 데스크톱 분할 화면은 유지하면서 모바일 가맹점 찾기 화면을 개선한다.

**구조:** `App.css` 마지막에 모바일 전용 규칙을 두어 기존 반응형 규칙보다 우선 적용한다. Node 테스트는 핵심 화면 너비 규칙을 확인한다.

**기술:** React, TypeScript, CSS, Node 내장 테스트, Vite.

## 제약

- 표현 규칙만 수정하며 가맹점·필터·카카오맵 동작은 바꾸지 않는다.
- 760px 이하에서 모바일 규칙을 적용하고, 390px 이하에서는 헤더를 더 압축한다.
- 기존 한국어 문구와 데스크톱·태블릿 동작을 유지한다.

## 완료 항목

- [x] 좁은 화면의 헤더·지도 오버레이·푸터 간격을 조정했다.
- [x] 전체 테스트와 프로덕션 빌드를 실행했다.
