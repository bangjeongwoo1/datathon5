# 가맹점 데이터 연결 구현 계획

**목표:** 예시 가맹점 목록을 실제 가맹점 데이터로 교체하고, 근거 없는 전화 기능을 제거한다.

**구조:** CSV 변환기가 화면에 필요한 필드만 가진 TypeScript 데이터 모듈을 생성한다. 정규화 모듈은 원본 업종을 화면용 큰 분류와 상세 분류로 변환하고, React는 생성된 목록을 그대로 사용한다.

**기술:** React, TypeScript, Vite, Node 내장 테스트, Python CSV 변환 스크립트.

## 제약

- 화면 가맹점 원본은 좌표 통합 CSV만 사용한다.
- 관리기관 전화번호를 매장 전화번호로 표시하지 않는다.
- `업종명`을 보존하고 `공식_업태명`은 값이 있을 때만 사용한다.
- 지도 초기 로딩에서 전체 가맹점 주소를 일괄 검색하지 않는다.

## 완료 항목

- [x] 편의점·제과점·식사 업종·기타 업종과 빈 상세 업태의 분류를 테스트했다.
- [x] `merchantData.ts`에서 원본 필드를 화면 모델로 변환했다.
- [x] `generate_merchants.py`가 CSV를 `merchants.generated.ts`로 생성하도록 구현했다.
- [x] 카드와 팝업에서 전화번호·전화 기능을 제거했다.
- [x] 저장된 좌표가 있는 매장만 지도 마커 대상으로 설정했다.

## 원본 필드

생성 데이터는 `id`, `name`, `address`, `industry`, 선택적 `officialBusinessType`, 선택적 `coordinates`를 사용한다. 좌표가 없는 매장은 목록에는 남고 지도 마커만 표시하지 않는다.
