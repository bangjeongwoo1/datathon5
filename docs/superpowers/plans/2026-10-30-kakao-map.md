# 카카오맵 연동 계획

승인 범위: 기존 화면의 예시 지도를 카카오맵 Web SDK 지도로 교체한다. JavaScript 키는 로컬 환경변수로 관리한다.

- [x] SDK URL 검증과 좌표 파싱을 테스트했다.
- [x] 단일 SDK 로더, 로딩 실패 안내, 재시도와 타입 정의를 구현했다.
- [x] 춘천시 중심 지도, 업종별 색상 마커, 선택·확대·축소·시청 이동·반응형 리사이즈를 구현했다.
- [x] 목록 선택과 필터를 지도에 연결하고 SVG 예시 지도를 제거했다.
- [x] 저장된 위도·경도가 있는 매장만 지도 마커로 표시하도록 변경했다.

GPS는 요청하지 않으며, 위치 이동 버튼은 춘천시청 기준으로만 동작한다. `.env.local`은 Git에서 제외한다. 실제 SDK 인증과 타일 표시는 등록한 도메인의 브라우저에서 확인한다.
