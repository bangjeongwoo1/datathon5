# 가맹점 찾기 화면 구현 계획

**목표:** 춘천시 아동급식카드 가맹점을 찾는 React 프로토타입을 구현한다.

**구조:** 가맹점 데이터 정규화, 검색·필터 함수, 좌측 목록과 우측 지도 분할 화면으로 구성한다. 로그인·회원가입·카드 등록 기능은 포함하지 않는다.

**기술:** React, TypeScript, CSS, Vite.

## 완료 항목

- [x] 검색·업종 필터·빈 결과·정렬을 테스트했다.
- [x] 가맹점 데이터와 필터링을 구현했다.
- [x] 데스크톱 분할 화면, 반응형 화면, 접근 가능한 조작 요소를 구현했다.
- [x] 목록 선택과 지도 팝업·군집 동작을 연결했다.

지역 선택은 춘천시 범위만 지원하며 GPS 위치를 수집하지 않는다.
