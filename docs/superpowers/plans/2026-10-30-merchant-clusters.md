# 가맹점 군집 마커 구현 계획

**목표:** 지도를 축소했을 때 가까운 가맹점을 숫자 군집으로 묶고, 군집을 누르면 해당 가맹점 목록만 왼쪽 패널에 표시한다.

**구조:** 카카오 MarkerClusterer를 사용한다. 군집 클릭 시 확대 전에 원래 마커 ID를 수집하고, 선택 군집은 왼쪽 목록에만 적용한다. 다른 군집은 계속 선택할 수 있으며 전체 목록 보기로 해제할 수 있다.

- [x] 군집의 정확한 구성원, 중복·알 수 없는 마커, 필터 교집합과 목록 복원을 테스트했다.
- [x] 단일 군집 인스턴스, 업종별 색상 마커, 클릭·키보드 조작과 정리를 구현했다.
- [x] 선택 지역 수, 전체 목록 복귀와 지도 확대 동작을 연결했다.

군집은 지도 레벨 4부터 80px 격자로 묶는다. 저장된 좌표가 없는 매장은 군집과 마커에서 제외한다.
